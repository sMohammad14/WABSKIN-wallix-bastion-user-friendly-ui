به پیشنهاد یکی از دوستان، تصمیم گرفتم یک پوسته کاربر پسند برای WALLIX Bastion بنویسم.

اگر با ولیکس کار کرده باشید به طور کامل با ضعف های پوسته اش آشنا هستید.

به هر حال، فایل آپلود شده صرفا برای مشاهده و ادیت دیوایس ها سرویس های اعمال شده بهش هست، از قابلیت هاش میشه به این اشاره کرد که، میتونه در یک پنده واحد و بدون pop-up های آزاردهنده تمام دستگاه های تعریف شده در ولیکس رو ادیت کنه.

در حال حاضر امکان حذف سرویس از دستگاه (تمام سرویس ها) و امکان حذف/ اضافه کردن sub-protocol برای RDP و SSH رو داره. نام دستگاه، آدرس، توضیحات و Alias دستگاه رو هم میشه ادیت کرد. یک نمایشگر لاگ هم وجود داره براش  برای دیدن خطا های احتمالی.
قدم قعدی برنامه دارم امکان حذف/اضافه کردن دستگاه و اضافه کردن سرویس رو هم اضافه کنم.

ابتدا امکاناتی اضافه میشن که بیشترین کاربرد رو دارن سپس امکانات کمتر مورد استفاده اضافه خواهد شد.

البته نیاز دوستان هم تاثیر گذار خواهد بود که کدوم ویژگی اولویت بالاتری داشته باشه. این پروژه کم کم سایر موجودیت ها مثل یوزر و گروه ها و ... رو شامل میشه.

دوتا باگ هم پیدا کردم که در نوع خودش حالب بود، شما میتونید دستگاه بدون نام داخل این سامانه اضافه کنید! و دستگاهی رو مکه دسترسی اتصال روی protocol خاصی بهش ندارید رو سرویس هاش رو ادیت کنید!
